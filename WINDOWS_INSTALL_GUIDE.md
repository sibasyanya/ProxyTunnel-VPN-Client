# ProxyTunnel VPN Client for Windows 11 — Инструкция по установке и сборке .exe

Это руководство объясняет, как запустить и скомпилировать ProxyTunnel в виде полноценного установочного `.exe` файла на вашем компьютере Windows.

---

## 🚀 Вариант 1: Сборка в один клик через Tauri (Рекомендуемый способ)

Tauri создает ультра-легкий нативный `.exe` инсталлятор (размером всего 10–15 МБ) с поддержкой иконки в системном трее Windows, фоновой работы и интеграции с сетевым драйвером Wintun.

### Шаги:

1. **Скачайте проект из Google AI Studio**:
   - В правом верхнем углу интерфейса AI Studio нажмите **Export** -> **Download ZIP** (или экспортируйте в ваш GitHub).
   - Распакуйте архив в любую папку (например, `C:\ProxyTunnel`).

2. **Требования на вашем ПК**:
   - Установлен **Node.js** (v18 или новее): [https://nodejs.org](https://nodejs.org)
   - Установлен **Rust**: [https://rustup.rs](https://rustup.rs) (стандартная установка)
   - Microsoft C++ Build Tools (предлагаются установщиком Rust)

3. **Сборка инсталлятора**:
   - Откройте терминал (PowerShell или CMD) в папке проекта и выполните:
   ```bash
   # 1. Установка зависимостей
   npm install

   # 2. Компиляция установочного .exe файла
   npx tauri build
   ```
   *Или просто запустите файл `build-windows.bat` двойным кликом мышью.*

4. **Готовый файл**:
   После завершения компиляции ваш готовый файл инсталлятора будет лежать по адресу:
   `src-tauri\target\release\bundle\nsis\ProxyTunnel_1.1.0_x64-setup.exe`

---

## 📦 Вариант 2: Сборка классического инсталлятора через Inno Setup

Если вы хотите собрать классический Windows инсталлятор:

1. Скомпилируйте веб-часть:
   ```bash
   npm install
   npm run build
   ```
2. Установите бесплатную программу [Inno Setup 6](https://jrsoftware.org/isdl.php).
3. Откройте в Inno Setup файл `installer.iss` из корня проекта и нажмите **Compile** (зеленая стрелочка или Ctrl+F9).
4. Готовый инсталлятор появится в папке `Output\ProxyTunnel-Windows11-Setup.exe`.

---

## 🛡️ Как работает перехват трафика на уровне Windows:

1. **Wintun Network Interface**: При установке драйвер `wintun.dll` регистрирует виртуальный сетевой адаптер Layer 3 TUN.
2. **Маршрутизация 0.0.0.0/0**: При нажатии «Подключить» весь сетевой стек Windows перенаправляется через локальный сокет, шифруется и передается на ваш SOCKS5 / HTTP прокси.
3. **Split Tunneling (Исключения)**: Драйвер фильтрует пакеты по пути к исполняемому файлу (например, `C:\Program Files\Google\Chrome\Application\chrome.exe`) через WFP (Windows Filtering Platform) API, пропуская трафик исключенных программ напрямую через ваш физический Wi-Fi/Ethernet.
